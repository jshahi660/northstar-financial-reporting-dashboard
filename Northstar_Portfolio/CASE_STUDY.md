# Northstar Financial Reporting Dashboard

**Financial Reporting · Spreadsheet Analysis · Dashboard Automation**

## Project overview
Northstar is a financial reporting dashboard prototype demonstrating how financial data can be transformed into a structured management report. It combines a browser-based dashboard, financial calculations, monthly summaries, and PDF report generation.

- Project type: Independent portfolio project
- Tools: HTML, CSS, JavaScript, browser-based PDF export
- Reporting period: FY2025
- Dataset: Fictional financial data

## What I built
- Executive dashboard for revenue, expenses, operating profit, margin, receivables, and payables
- Monthly revenue, expense, and profit reporting with a comparison chart
- Annual profit and loss summary
- Balance sheet reconciliation checks
- Accounts receivable and payable tables
- Printable six-page PDF report
